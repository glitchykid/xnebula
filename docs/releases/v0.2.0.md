# XNebula v0.2.0

Runnable milestone: download the Windows x64 ZIP, extract it, and double-click `Start-XNebula.cmd`. Python 3.15.2 is included; no Python setup, pip, or Git is required to run the portable release.

## Changes

- Add standard and explicit administrator PowerShell launchers with argument and exit-code forwarding.
- Add a compact terminal menu for scans, selected removals, privacy, startup, background apps, storage, Recall, restore, profiles, and reports. All changes still preview before explicit confirmation.
- Add a checksum-verified portable builder, a bundled Python license, quick-start instructions, and ZIP checksum output.
- Keep relative profiles, backups, and logs in the extracted app folder, even when launched from elsewhere.
- Build and test the actual portable ZIP in Windows CI.

## Validation and limitations

Validation on Python 3.15.2: 74 passing tests, 98% combined application statement/branch coverage, clean Ruff lint/format checks, and successful wheel, source, and portable builds. Unit and PowerShell integration tests cover menu cancellation/confirmation, argument handling, corrupt/incomplete runtime archives, missing-runtime errors, portable startup, quoted paths, exit codes, and administrator command encoding. Windows CI builds the portable ZIP before the test suite.

The portable build targets Windows 11 x64. Real UAC approval/cancellation remains a manual check; automated tests validate the elevated command payload without launching a privileged process. Native destructive Windows operations and effective privacy policy behavior still require elevated-VM validation. Existing edition restrictions and recovery limitations apply.
