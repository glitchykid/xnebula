# XNebula v0.3.2

Runnable Windows x64 maintenance release.

- Keep the menu selection and repeat confirmation after a mistyped APPLY; Enter cancels.
- Use plain output and numbered selection when TERM=dumb or terminal controls are unavailable.

Four agents contributed UX, terminal UI, functionality and independent code review; the final review found no outstanding issues.
