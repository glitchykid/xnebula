# XNebula v0.2.1

Runnable usability update: app removal in the terminal menu now uses numbers instead of requiring typed app IDs.

- Choose multiple apps with spaces, commas, or ranges (`1 3 5`, `1,3,5`, `2-4`).
- Choose the numbered **Select All** option, or enter `all`, to select every supported app.
- Review the selected app names before the existing removal preview and `APPLY` confirmation.
- Correct invalid selections without reopening the picker; `0` or Enter cancels.
- Retain app IDs for CLI commands and saved profiles.

Validation: 84 passing tests, 97% combined statement/branch coverage, clean lint and formatting, and successful package builds. Tests include parser boundaries, invalid and duplicate entries, cancellation, Select All, actual preview/apply flows with a simulated backend, and the numbered picker inside the extracted portable release. Native destructive operations and real UAC approval remain manual elevated-VM checks.
