# XNebula v0.3.0

Runnable milestone: simplify the portable PowerShell app around Windows app removal, optional services, privacy, animations, Edge removal, and recovery.

## Changes

- Replace the eleven-option menu with six focused, colored actions on a black console background.
- Discover removable Microsoft Appx/MSIX apps dynamically, with numbered selection and Select All; preserve essential Windows components and unrelated desktop programs.
- Close processes only within selected app directories, attempt all selected package removals, and report individual failures.
- Disable optional Windows services with dependency checks and backups preserving startup/running/delayed-start state.
- Expand privacy controls to packaged-app permissions, background activity, speech, clipboard sync, and integrated Recall controls.
- Disable and restore Windows-managed animations using native preference APIs and taskbar settings.
- Force uninstall Edge using its signed installer, with an explicit, tightly scoped force-delete fallback when it remains installed. Preserve WebView2 and profile data and distinguish file deletion from a normal uninstall.
- Remove profile/startup/storage/background-picker/report features while retaining automatic logs, numbered recovery, and validation for older registry backups.

## Validation and limitations

Local validation: 104 passing tests, 93% combined statement/branch coverage, and passing lint/format checks. Portable, wheel, and source distributions are built for the release. Production PowerShell scripts are exercised through substitute cmdlets; native service/ownership/file-deletion calls are intercepted. Animation preferences are tested against an in-memory API. No destructive host operation is part of the test suite.

Actual elevated operations, effective Windows privacy policy enforcement, console visual rendering, and real UAC approval still need manual disposable-VM validation. Edition/build restrictions apply. Force-closing apps can lose work. Service/privacy changes can disable useful features. Forced Edge file deletion is not a clean supported uninstall and can leave registration entries or be reversed by updates. Removed apps, files, data, and Recall snapshots have no settings-backup undo.
