# XNebula v0.4.0

Runnable Windows x64 release focused on finding, reviewing and correcting selections.

- Search app and service checklists without losing selections outside the filter.
- Select or clear only the matching rows with A while a filter is active.
- Keep an empty checklist open on Enter, with a hint to select an item or cancel.
- Return from the preview with EDIT, retaining checked items, and preview the revised selection before applying.
- Show scan activity and explicit completion, cancellation or failure feedback in the menu.
- Distinguish backups by timestamp, type and filename; continue listing readable backups when another file is invalid or inaccessible.

Validation: 173 passing automated tests, including real menu/search/edit/planner workflows and extracted portable launchers; 94% combined statement/branch coverage; Ruff lint and formatting; portable ZIP, wheel and source builds. Independent code review found no blocking issues. The README includes a preview rendered from the actual checklist with sample data, bundled in the portable ZIP. Tests substitute Windows mutations; native destructive operations, UAC and visual rendering still require manual verification in a disposable Windows VM.
