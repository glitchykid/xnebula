# XNebula v0.1.0

First runnable Python terminal release for Windows 11. This is an application milestone, not a documentation-only release.

## Changes

- Preview and remove eight optional bundled apps across existing accounts and future-account provisioning.
- Configure advertising, diagnostic, tailored-content, activity-history, and location policies.
- Disable selected Run startup entries and packaged-app background activity.
- Configure Storage Sense with explicit Downloads/Recycle Bin retention choices.
- Detect supported Recall installations and disable snapshot saving.
- Save reusable JSON profiles, restore registry backups, and report action-journal outcomes.
- Include Windows CI, pinned development tools, a README, and versioned wiki pages.

## Validation

Python 3.15.1 on Windows 11; 53 passing unittest tests, 97% combined statement/branch coverage, passing Ruff lint/format checks, wheel/source package builds, and installed-wheel CLI smoke checks. The coverage gate is 90%. PowerShell integration tests use substitute Appx/DISM commands; registry mutation tests use an in-memory implementation.

## Limitations

Live system-wide scanning/removal and native registry mutation were not validated in an elevated disposable VM. The development terminal is non-administrator. Policy availability varies by edition and build; successful registry writes do not prove effective policy enforcement. Startup support is limited to Run registry values. User-scoped policies affect the running account. App data, deleted files, and Recall snapshots are not recoverable from registry backups. Profiles can partially apply and stop on the first error.
