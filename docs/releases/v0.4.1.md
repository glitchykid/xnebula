# XNebula v0.4.1

Runnable Windows x64 reliability release following a runtime logic review.

- Bind menu APPLY to the reviewed plan; refuse changed plans before mutations.
- Pin animation and service recovery plans across confirmation; do not reread a replacement backup to choose the action after confirmation.
- Refuse changed app/Edge inventory after typed confirmation and changed animation preferences before applying.
- Validate registry changes and case-insensitive duplicate startup value names before creating backups or writing.
- Require integer snapshot schema versions and valid dependency/removal field types.
- Compare service dependencies without case sensitivity and tighten Appx publisher CN boundaries.
- Skip confirmation and writes when animations are already disabled.

Validation: 209 passing automated tests, 96% combined statement/branch coverage; Ruff lint and formatting; portable ZIP, wheel and source builds. Independent review found no additional high/medium priority defects in the changes. Regression tests first reproduced confirmation races, replacement backups, schema/value validation and publisher matching errors. See the [logic review](../reviews/logic-review-2026-11-03.md) for findings, regression evidence and limitations. Tests substitute Windows mutations; real elevated/destructive Windows operations and power-loss recovery remain unverified in a disposable VM.
