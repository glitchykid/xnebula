# XNebula v0.3.1

Runnable Windows x64 release with keyboard checklists.

- Use Up/Down to navigate app and service names, Space to toggle, A to select/clear all, Enter to confirm, and Esc to cancel.
- Remove item descriptions from selection lists; retain the action preview before APPLY.
- Scroll long lists within the terminal viewport. NO_COLOR retains keyboard controls.
- Preserve the existing console theme; remove forced black/gray console settings.
- Retain built-in Windows PowerShell 5.1 and the included Python 3.15.2 runtime.
- Keep numbered input for redirected sessions and existing CLI commands.
- Give removable HEVC, HEIF, AV1, VP9, MPEG-2, Web Media, WebP, and Raw Image extensions readable checklist names; cover individual and all-selection removal with a regression test.

Validation: 126 passing automated tests covering checklist, menu, native adapters, packaging, and portable launchers; 93% combined coverage; Ruff lint/format checks; portable ZIP, wheel, and source builds. Director and independent UX review completed. Tests substitute Windows mutations. Actual visual appearance and destructive actions still require manual verification in a disposable Windows VM.
