XNebula - Windows 11 x64

Extract the entire ZIP. Open Start-XNebula-Admin.cmd and accept Windows'
administrator prompt. Python is included; no installation or network is needed.
Keep .runtime, src, and scripts with the launchers.

Windows PowerShell keeps your console theme and displays colored messages.

1  Remove Windows apps       2  Disable optional services
3  Apply privacy settings    4  Disable Windows animations
5  Force uninstall Edge      6  Restore a backup
0  Exit

In app/service checklists, use Up/Down to move and Space to toggle a checkbox.
A selects or clears all. Enter confirms; Esc goes back. Lists show names only.
Press / to search, type a name, then Enter to navigate the matches.
A selects/clears matching rows; checked items outside the filter stay selected.
Esc clears the filter first; press Esc again to go back.
Review the action preview, then type APPLY to proceed or EDIT to revise choices.
In the numbered editor, Enter keeps previous choices; new numbers replace them.
Redirected input uses numbers, ranges (1,3-5), all, and 0 to cancel. Opening the app makes no system changes.

All-app removal includes detected removable Microsoft packages such as Store,
Photos, Xbox, and Copilot. Core Windows components and third-party programs
are excluded. Edge has its own force-removal action. Save your work first:
selected apps can close, and removed app data is not backed up.

Read service effects: Select All can disable printing, search indexing, Xbox,
location, and other optional features. Privacy changes can block camera,
microphone, background notifications, and speech features.

Edge removal tries its signed uninstaller, then can force-delete its validated
installation files. WebView2 and browser profiles are excluded. Reinstall Edge
to recover it; force deletion can leave a registration entry or be undone by updates.

Backups are in .xnebula\logs. Restore them by number in menu option 6.
Rows show local time, type and filename; unreadable files are counted and skipped.
Backups restore settings/services, not removed apps, files, or Recall snapshots.

PowerShell commands also work:
  .\Start-XNebula.cmd --help
  .\Start-XNebula-Admin.cmd remove all --apply
  .\Start-XNebula-Admin.cmd services disable all --apply
  .\Start-XNebula-Admin.cmd privacy set all --apply
  .\Start-XNebula-Admin.cmd animations disable --apply
  .\Start-XNebula-Admin.cmd edge remove --apply

Update by extracting a new release into a new folder; keep your old backups.
Deleting XNebula's folder does not undo Windows settings. See README.md.
